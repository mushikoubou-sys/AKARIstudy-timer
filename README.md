# AKARI Study Timer

小学生が毎日の学習とピアノ練習を楽しく記録できる、スマートフォン優先の学習タイマーです。

## 主な機能

- 7科目それぞれのスタート・一時停止・再開・完了・完了取り消し
- 同時タイマー防止と、再読み込み後の計測復元
- 日別の学習時間・完了数・ポイントをブラウザに保存
- 1週間／科目別グラフ、日別記録、ごほうび交換
- 保護者向けのお名前・ごほうび設定
- レスポンシブ表示、PWA／オフライン対応

## 公開方法

静的ファイルだけで動作します。GitHub の Settings → Pages で、公開元を `main` ブランチのルートに設定してください。
